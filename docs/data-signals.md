# Data Signals

## Purpose

MarketTrust builds trust and readiness from verified behaviour, not self-declared claims.

## Trader Signals

- payment count
- payment volume
- payment consistency
- task funding frequency
- dispute ratio
- account age

## Worker Signals

- task acceptance count
- completion ratio
- start code success rate
- verification success rate
- payout success rate
- dispute ratio
- on-time completion trend

## Platform Signals

- funded-to-assigned conversion
- verification latency
- payout settlement latency
- notification delivery reliability
- dispute resolution turnaround

## Output Surfaces

- worker task match score
- trader trust score
- worker trust score
- financial readiness tier
- dispute risk flags

All scoring should remain explainable and reversible over time with new behaviour.
