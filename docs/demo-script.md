# Demo Script (Draft)

## Narrative

MarketTrust turns verified informal activity into trust and readiness signals for inclusion-friendly financial services.

## Required Flow

1. Trader onboarding and profile activation.
2. Trader static virtual account identity display.
3. Customer payment recorded and verified.
4. Ledger/notification update shown.
5. Trader creates task.
6. Trader funds task.
7. Task moves to `FUNDED` and matching begins.
8. Worker accepts funded task.
9. Verification signal flow (`START_CODE` and completion proof).
10. Trader confirms completion.
11. Worker payout initiated and status tracked.
12. Trust + readiness profile update.

## Key Lines to Say

- Squad is the transaction truth layer.
- Workers only receive funded opportunities.
- AI uses verified behavioural signals, not fake profile claims.
- Financial readiness is tiered guidance, not instant loan approval.
