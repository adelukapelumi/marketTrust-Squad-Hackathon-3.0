# Judging Alignment (Challenge 02)

## Problem Fit

MarketTrust targets youth unemployment and fragmented informal trade by connecting traders, workers, and financial services.

## Squad Depth

The architecture and data model position Squad on core flows:

- trader payment identity (virtual accounts)
- payment verification
- funded task gating
- payout execution and tracking

## Intelligence

MVP intelligence is explainable scoring:

- worker-task match score
- trust score events
- readiness tier updates
- dispute risk indicators

## Inclusion

Mobile-first UX with backend-compatible channel expansion to USSD, SMS, and WhatsApp.

## Scalability

- normalized transaction/event model
- status-driven orchestration
- auditable financial state transitions
- package-based shared contracts for app consistency
